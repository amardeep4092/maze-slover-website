🎮 Game Objective & Controls

Navigate your player P from the Start cell S to the Exit cell E in the shortest time and lowest move count.

  • Movement: Use Arrow Keys or W, A, S, D (or the on-screen Directional Pad).
  • Walls (#): Solid obstacles. The player cannot pass through them.
  • Restart: Resets your player to Start without generating a new layout.
  • New Maze: Generates a fresh, uniquely solvable randomized maze.

🧠 Data Structures Implemented

1. 2D Array Matrix

The maze grid is modeled as grid[rows][cols] where each coordinate maps to Wall (1), Path (0), Start (2), Exit (3), or Visited markers.

2. Stack (LIFO)

Used by Depth-First Search (DFS). Coordinates are pushed as the search advances and popped during backtracking when dead-ends are encountered.

3. Queue (FIFO)

Used by Breadth-First Search (BFS). Coordinates are enqueued and explored level-by-level, mathematically guaranteeing the shortest path.

4. Visited Array & Recursion

A 2D boolean array prevents infinite cycles. Maze generation leverages recursive call-stack backtracking.
